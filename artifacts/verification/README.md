# Проверочные снимки

Снимки настоящего Electron, обновляемые `npm run test:electron`:

- `selection.png` — шесть стран и три уровня сложности ИИ.
- `controls.png` — отдельные подсказки P1 и P2 для Японии и Афганистана.
- `fight.png` — бой Японии против Афганистана, арена и HUD.

Это результаты визуальной проверки интерфейса, не игровые ассеты и не доказательство ручного плейтеста. Общие результаты и ограничения проверки находятся в корневом README.
