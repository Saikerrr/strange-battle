# Проверочные снимки

Снимки настоящего Electron, обновляемые `npm run test:electron`:

- `selection.png` — шесть стран и три уровня сложности ИИ.
- `controls.png` — отдельные подсказки P1 и P2 для Японии и Афганистана.
- `fight.png` — бой Японии против Афганистана, арена и HUD.
- `main-menu.png` — новое стартовое меню с оригинальными изображениями пользователя.
- `main-menu-hover.png` — наведение на PVP: увеличение и подсветка.
- `main-menu-pressed.png` — PVP во время нажатия: сжатие.
- `main-menu-small.png` — меню в уменьшенном окне с сохранёнными пропорциями.
- `selection-skills.png` — металлическая панель описания способностей.
- `practice-selection.png` — фиксированный манекен на выборе полигона.
- `practice.png` — манекен без ног, новый HUD и арена.

Снимки игрового Canvas экспортируются из настоящего renderer Electron после
окончания перехода; размеры окон и попадание мышью проверяются отдельно.

Это результаты визуальной проверки интерфейса, не игровые ассеты и не доказательство ручного плейтеста. Общие результаты и ограничения проверки находятся в корневом README.
