# Strange Battle 1.9

HTML/Canvas-файтинг в Electron. Сохранены шесть стран, PvP на одной клавиатуре, PvE с тремя уровнями сложности и полигон.

## Запуск в VS Code

Открой эту папку в VS Code, затем в его терминале:

```powershell
npm install
npm start
```

Если зависимости уже установлены, достаточно `npm start`. Для окна с консолью разработчика используй `npm run dev`. Открывать `index.html` двойным щелчком не нужно: игра загружает ES-модули через Electron.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `main.js` | Главное окно Electron; Node.js недоступен игровому JavaScript |
| `index.html`, `style.css` | Canvas и оформление окна |
| `game.js` | Создание игры и запуск кадрового цикла |
| `src/engine/` | Сборка модулей, начальное состояние, ввод, настройки арены, звук и эффекты |
| `src/entities/` | Базовый боец: движение, физика, атаки, получение урона и вызовы обработчиков |
| `src/characters/` | Способности и особенности шести стран; `roster.js` — единый список для выбора, названий, цветов и флагов |
| `src/ai/controller.js` | Принятие решений ботом для всех стран |
| `src/ai/difficulty.js` | Параметры лёгкой, средней и высокой сложности |
| `src/systems/` | Матч, раунды, снаряды, предметы, ультимейты и эффекты состояний |
| `src/rendering/` | Арена, бойцы, игровые объекты, камера и порядок отрисовки |
| `src/ui/` | Меню, выбор стран, управление, пауза и HUD |
| `tests/`, `scripts/test-electron.cjs` | Проверки логики и запуск проверок в настоящем Electron |

Модули получают общий контекст игры через `register(context)`. Он даёт доступ к текущим бойцам, состоянию матча, Canvas и сервисам, не создавая циклических импортов. `src/engine/create-game.js` явно подключает модули и выбирает обработчики. Методы бойца больше не переопределяются цепочками `Fighter.prototype` при загрузке стран.

Внутренние суффиксы `_base`, `_arena`, `_interface` обозначают сохранённые слои исходных механик: базовое поведение, расширения арены и последующие дополнения. Вызовы между ними явные. Менять баланс следует в соответствующем обработчике страны или общих настройках, а не в HTML-копиях.

## Управление

| Действие | P1 | P2 |
| --- | --- | --- |
| Движение, прыжок, блок | A / D, W, S | Стрелки |
| Двойной прыжок | Повторное W в воздухе | Повторное ↑ в воздухе |
| Дэш | Левый Shift | Правый Shift |
| Удары | F / G / H | Num4 / Num5 / Num6 или `,` / `.` / `/` |
| Способности | Z / X / C | Num1 / Num2 / Num3 или 1 / 2 / 3 |
| Зарядка ультимейта | R | Num0 или 0 |
| Пауза | Esc | Esc |

Особенности способностей доступны по кнопке `?` рядом с каждой страной. На полигоне `+` добавляет манекен с 200 HP.

## Исправления

- Восстановлены связи способностей, ультимейтов и отрисовки, потерянные при первоначальном разделении 1.8.
- Из 1.9 перенесены Япония, Афганистан и настройки сложности ИИ.
- При выборе страны сбрасываются флаги предыдущего персонажа и состояние манекена.
- Новый раунд очищает снаряды и эффекты всех стран, включая призраков и объекты Афганистана.
- Поджог и замедление Китая обрабатываются на противниках любой страны.
- Пауза и остановка кадра при попадании замораживают также специальные снаряды.
- При потере фокуса клавиши отпускаются и бой ставится на паузу; удержание Enter не пропускает экраны.
- Подсказки для обоих игроков соответствуют управлению; кнопка возврата на экране управления помещается в окно.

## Проверка

```powershell
npm test
npm run test:electron
npm run format:check
```

Первая команда проверяет все страны на обеих сторонах, зарядку ультимейтов через ввод, меню, сложности, полигон, очистку раундов и исправленные ошибки. Вторая запускает скрытое окно Electron, проверяет 36 сочетаний стран, способности в усиленных формах и реальные вызовы Canvas; снимки экрана сохраняются в `artifacts/verification/`. Это автоматические проверки работоспособности, а не полная проверка баланса и всех сочетаний способностей.

Исходные `SB 1.7 china — копия.html` и `SB JAPAN UPD.html` оставлены без изменений для сравнения. Рабочая игра использует модули `src`.

Причина исходных поломок: при переносе из общего замыкания некоторые зависимости и вызовы были потеряны; дополнительные версии функций не всегда подключались к игровому циклу. Контракт сборки теперь явный: `register(context)`, общие данные в контексте, итоговые назначения в `create-game.js`. Сохранения, новые механики, баланс и установщик в объём работы не входили.

Ограничения проверки: **degraded — точная версия Electron 31.7.7**. В поставленной папке пакет объявляет 31.7.7, но имеющийся исполняемый файл сообщает 45.2.3; runtime-проверки прошли на этом локальном файле. До изменения правил проекта восстановлен отсутствовавший `node_modules/electron/path.txt`, чтобы стандартный launcher находил имеющийся бинарник. Версия зависимости не обновлялась; чистая установка заявленной версии отдельно не проверена.

**degraded — ручной плейтест со звуком и клавиатурой**: автоматизация проверила обработчики и отрисовку, но не ощущение управления человеком и воспроизведение звука. Для приёмки запусти `npm start`, сыграй Японией против Афганистана, проверь Z/X/C/R, Esc, повторный матч и полигон. Пользовательская оценка баланса остаётся отдельной задачей.
