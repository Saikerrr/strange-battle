# Флаги стран

Точные SVG из lipis/flag-icons, версия v7.3.2, лицензия MIT (см. LICENSE):
https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3

`ua`, `ru`, `us`, `cn`, `jp`, `af` соответствуют шести странам игры.
Для Афганистана сохранён республиканский триколор с гербом из авторского
макета. Это художественный выбор игры, не заявление о текущем официальном флаге.

На экране выбора поверх точного изображения рисуются изгибы, светотень,
тонкая фактура ткани и шов. Звёзды и гербы не генерируются заново.
