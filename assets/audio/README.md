# Музыка и звуки

- `dark-city.wav` — предоставленный пользователем Dark City, оригинал из
  `Obsidian Vault/images/Dark City.wav`, 200,6 секунды; без изменения аудио.
- `hover.ogg` — Kenney Interface Sounds `switch_002.ogg`.
- `click.ogg` — Kenney Interface Sounds `click_003.ogg`.
- `transition.ogg` — Kenney Interface Sounds `open_001.ogg`.

Источник UI-звуков: https://kenney.nl/assets/interface-sounds (CC0).
Оригинальный архив хранится в JS-проекте в `assets/audio/source/`,
лицензия — `Kenney-License.txt`. В Godot музыка звучит на −12 дБ,
повторяется и затухает за 260 мс при выходе на арену. После возвращения
в меню начинается сначала. Боевое попадание использует короткий звук,
который генерируется в Godot.
