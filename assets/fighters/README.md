# Спрайты бойцов

Прозрачные растровые позы сгенерированы встроенным ImageGen. Сначала создан
общий лист оригинальных персонажей в порядке Украина, Россия, Америка /
Китай, Япония, Афганистан. Остальные листы используют его как референс.
Ячейки обрезаны по непрозрачным пикселям и сохранены отдельно для Godot.

Запросы к генератору задавали один стиль рисованного аркадного файтинга,
вид вправо и отдельные непересекающиеся ячейки 3×2. Исходные образы включали
сине-жёлтую куртку и бинты, тёмное пальто и ушанку, спортивную куртку со звёздами,
красно-золотую одежду с драконом, чёрный костюм с белым поясом и зелёный плащ
с песочным шарфом. Для вариантов запрошены бег, прыжок, блок, прямой удар,
боковой удар ногой, апперкот, промежуточная фаза бега, подготовка навыка,
реакция на попадание и победная стойка.
Отдельный лист ультформ содержит зомби, киборга, крылатого бойца, золотого
дракона, призрачного самурая и усиленного бойца Афганистана.

`../game/arena.png` сгенерирована тем же инструментом по запросу широкой
аркадной арены в ночном индустриальном зале с трибунами и синими и красными
прожекторами. Пол, платформы и трамплины рисуются движком.
